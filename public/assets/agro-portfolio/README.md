# BritAsia Agro Portfolio — Section Assets

## Included
- `images/agro-farm-portfolio.webp` — cropped livestock/farm visual for the portfolio section.
- `images/section-design-reference.webp` — full section mockup for visual reference only.
- `icons/` — lightweight, editable SVG icons for livestock, poultry, aquaculture, cold chain, ethical husbandry, institutional quality, vision and mission.
- `styles/brand-tokens.css` — brand colors and typography tokens.

## Brand system
- Forest text: `#013D26`
- Accent green: `#68A617`
- Display typography: Playfair Display
- Body typography: Inter

Use the SVG files directly as image assets or inline them in the frontend. Do not use the full mockup image as the actual webpage section; rebuild the layout with HTML/CSS and use the mockup only as a reference.
