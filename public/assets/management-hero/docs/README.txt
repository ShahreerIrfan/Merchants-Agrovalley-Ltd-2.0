MANAGEMENT HERO — ASSET PACKAGE

All visual assets are separate files for a real responsive web implementation.
The main facility photograph is newly generated as a standalone image; it is not a crop of the screenshot, PDF, or an infographic.

Folders:
- images/: WebP/JPG facility image and transparent PNG foliage.
- icons/: five individual SVG icons.
- shapes/: SVG divider/overlay/underline and CSS background gradient reference.
- docs/: Antigravity prompt.

Brand palette:
- Primary deep green: #013D26
- Secondary green: #005331
- Bright leaf green: #78C900 (use sparingly)
- Gold: #D7A72E
- White: #FFFFFF

Use the WebP photo for the right-side image. Use PNG foliage as decorative overlays with object-fit: contain.
Build the left dark background and glow with CSS. Use SVG gold curve as a mask/clip-path stroke overlay only if needed.
Do not use a flattened screenshot or the preview collage as a page background.
