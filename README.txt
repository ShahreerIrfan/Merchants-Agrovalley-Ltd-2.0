Folder structure:
public/
  images/hero-background.jpg
  logo/logo.png
  logo/merchants-agro-valley-logo.svg
  icons/ (7 individual SVG category icons)
docs/
  content.txt
  antigravity-prompt.md

Quick start:
1. Create the Next.js project using the command in docs/antigravity-prompt.md.
2. Copy the supplied public/ folder into the project root.
3. Open the project in Antigravity.
4. Paste the complete prompt from docs/antigravity-prompt.md.
5. Ask Antigravity to run lint/build and fix any issues.

The hero background is a 16:9 JPEG exported at 2560x1440.
The logo PNG is transparent. The editable logo SVG is also included.
Each category icon is a separate SVG file with transparent background.
